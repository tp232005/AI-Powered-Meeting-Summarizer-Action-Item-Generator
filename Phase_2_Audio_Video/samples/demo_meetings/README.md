# MeetMind demo meeting recordings

This folder contains five original English-language demo meetings with matching
transcripts. The four quick demos are each under two minutes; the planning
session runs for 10 minutes and 1 second. The recordings use locally generated,
synthetic English speech rather than real meeting participants.

| Recording | Duration | Scenario | Transcript |
|---|---:|---|---|
| `01_campus_event_checkin.wav` | Under 2 minutes | College event planning | `01_campus_event_checkin.txt` |
| `02_product_launch_standup.wav` | Under 2 minutes | Product launch stand-up | `02_product_launch_standup.txt` |
| `03_student_project_review.wav` | Under 2 minutes | Student team project review | `03_student_project_review.txt` |
| `04_department_budget_review.wav` | Under 2 minutes | Department budget review | `04_department_budget_review.txt` |
| `05_sustainability_program_planning_10_min.wav` | 10:01 | Organization and campus sustainability program | `05_sustainability_program_planning_10_min.txt` |

## Try the audio demos

1. Start MeetMind from the repository root.
2. Open **Analyze Meeting** and choose **Audio recording**.
3. Upload any `.wav` file in this folder and select **Transcribe**.
4. Review the transcript, then choose **Analyze meeting**.
5. View the summary, decisions, action items, risks, and readiness radar on
   the Results Dashboard.

The approximately ten-minute recording is below the default 30 MB upload limit and can be
used to demonstrate long-recording chunking. Transcription requires a configured
speech-to-text API key or a locally available Whisper model.
